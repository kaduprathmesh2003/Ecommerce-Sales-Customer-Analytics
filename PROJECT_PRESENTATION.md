# Interview presentation notes

1. **Problem:** An e-commerce team needs visibility into sales trends, customer value, category performance and order outcomes.
2. **Data:** Synthetic order records containing dates, customer IDs, products, quantities, discounts, cities and order statuses.
3. **Process:** Check duplicates and invalid quantities, calculate net line revenue, filter delivered orders for sales KPIs, and aggregate by month, category, city and customer.
4. **Tools:** Python/pandas for cleaning and analysis, MySQL for queries, Power BI for reporting, Streamlit for an interactive demo.
5. **Potential recommendations:** Review high-performing categories, investigate city-level differences, and examine cancellation/return patterns. Validate hypotheses with real operational data before acting.
6. **Limitations:** Synthetic data; no costs, marketing channels, website sessions, inventory or customer demographics.

## Resume bullet
Built an end-to-end e-commerce analytics project using Python, SQL and Power BI to analyze order trends, customer value, category performance and fulfilment outcomes; developed an interactive Streamlit dashboard.
